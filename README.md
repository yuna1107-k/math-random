# math-random

画面上に表示されているテキストを文字コード（Unicodeコードポイント）に変換し、
さらにランダムな基数（2進・8進・16進など）で変換した数値にその場で書き換えて表示する
Chrome拡張機能です。

## 仕組み

1. 任意のページを開くと、`content.js` が自動的に可視テキストノードを走査する
2. 各文字を `codePointAt()` で文字コードに変換し、設定中の基数（ランダム／2進固定／8進固定／16進固定、デフォルトはランダム）で `toString(radix)` 変換する
3. 変換後の文字列で元のテキストノードを書き換える
4. `MutationObserver` でDOMの変化を監視し、AI要約のストリーミング表示など後から追加・更新されるテキストも自動的に変換する
5. 変換対象のテキストノードは `requestIdleCallback` でアイドルタイム中に少しずつ処理し、サイト自体のスクロール・入力・アニメーションをブロックしないようにする
6. ポップアップから基数モードの変更（以後のページ読み込みに反映）、および今開いているページの変換ON/OFFの手動切り替えができる

## 読み込み方法（開発中）

1. `chrome://extensions` を開く
2. 「デベロッパーモード」を有効化
3. 「パッケージ化されていない拡張機能を読み込む」から本リポジトリのディレクトリを選択
