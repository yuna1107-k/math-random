# math-random

画面上に表示されているテキストを文字コード（Unicodeコードポイント）に変換し、
さらにランダムな基数（2進・8進・16進など）で変換した数値にその場で書き換えて表示する
Chrome拡張機能です。

## 仕組み

1. 任意のページを開くと、`content.js` が自動的に可視テキストノードを走査する
2. 各文字を `codePointAt()` で文字コードに変換し、設定中の基数（ランダム／2進固定／8進固定／16進固定、デフォルトはランダム）で `toString(radix)` 変換する
3. 変換後の各数値には、何進数で変換されたかが分かるよう基数をカッコ書きで付与する（例: `1a(36)`）。変換後の文字列は元のテキスト長に応じた上限で切り詰め、UI崩れを抑える
4. 変換後の文字列で元のテキストノードを書き換える（ブラウザのタブに表示されるタイトルも同様に変換する）
5. `MutationObserver` でDOMの変化を監視し、AI要約のストリーミング表示や、SPAによるタブタイトルの動的な書き換えなど後から追加・更新されるテキストも自動的に変換する
6. 変換対象のテキストノードは `requestIdleCallback` でアイドルタイム中に少しずつ処理し、サイト自体のスクロール・入力・アニメーションをブロックしないようにする
7. ポップアップから基数モードの変更（以後のページ読み込みに反映）、および今開いているページの変換ON/OFFの手動切り替えができる

## サイトの表示・操作を壊さないための除外対象

- アイコンフォント（Material Icons, Font Awesome等）のリガチャ表示
- `<select>`/`<option>` の選択肢テキスト（フォームの操作性を保つため）
- `aria-hidden="true"` が指定された装飾要素

## 開発ロードマップ

- Phase 1: 環境構築（manifest.json 等の骨組み）
- Phase 2: コア機能（文字コード変換・基数変換・DOM書き換え）
- Phase 3: UI/UX（ポップアップでのON/OFF・基数選択）
- Phase 4: 品質・パフォーマンス改善
- Phase 5: テスト
- Phase 6: 仕上げ・公開

## 読み込み方法（開発中）

1. `chrome://extensions` を開く
2. 「デベロッパーモード」を有効化
3. 「パッケージ化されていない拡張機能を読み込む」から本リポジトリのディレクトリを選択
