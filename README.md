# math-random

画面上に表示されているテキストを文字コード（Unicodeコードポイント）に変換し、
さらにランダムな基数（2進・8進・16進など）で変換した数値にその場で書き換えて表示する
Chrome拡張機能です。

## 仕組み

1. 拡張機能アイコンをクリックしてポップアップを開き、基数モード（ランダム／2進固定／8進固定／16進固定）を選択する
2. 「変換する」を押すと、現在のタブの可視テキストノードを走査する
3. 各文字を `codePointAt()` で文字コードに変換し、選択した基数で `toString(radix)` 変換する
4. 変換後の文字列で元のテキストノードを書き換える
5. もう一度押すと元のテキストに復元する

2. 「デベロッパーモード」を有効化
3. 「パッケージ化されていない拡張機能を読み込む」から本リポジトリのディレクトリを選択
